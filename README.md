# Emach Dizayn - Akıllı Üretim ve Dijital Çözüm Merkezi

Bu depo, **Emach Dizayn** bünyesinde Bandırma'daki üretim tesisimizde hayata geçirdiğimiz dijital dönüşüm projelerini ve açık kaynaklı yazılım bileşenlerini barındırmaktadır. Modern CNC teknolojisini e-ticaret lojistik süreçleriyle birleştiren bu altyapı, operasyonel verimliliğimizi artırmak için geliştirilmiştir.

## 🚀 Öne Çıkan Projelerimiz

*   **Emach-Kargo-Veri-Koprusu:** WooCommerce sipariş verilerini kargo takip sistemleriyle senkronize eden PHP tabanlı veri köprüsü.
*   **Whatsapp-Chatbot-Config:** Müşteri deneyimini iyileştiren, Botpress ve Meta Cloud API tabanlı akıllı asistan yapılandırması.
*   **CNC-Optimized-ArtCAM:** Üretim bandımızda kullandığımız ArtCAM 2008 ve 20W diyot lazer sistemleri için optimize edilmiş teknik ayarlar.
